
# NShell

A lightweight Unix-like shell implementation written in Go inspired by "Build your own shell" from [codecratfers](https://app.codecrafters.io/courses/shell/overview).

NShell is a learning-focused project that aims to recreate the core concepts behind a command-line shell, including command parsing, built-in commands, external command execution, and process management.

The project implements a simple interactive shell environment where users can execute commands, pass arguments, and interact with the underlying operating system through Go's system interfaces.
